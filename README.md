# Publications and Related Research

## Semantic Similarity-Informed Bayesian Borrowing for Quantitative Signal Detection of Adverse Events

### Preprint
https://arxiv.org/abs/2504.12052

### Summary

This work introduces a semantic similarity-informed Bayesian borrowing framework for quantitative pharmacovigilance signal detection. Related adverse event concepts contribute evidence according to clinical similarity rather than binary hierarchy inclusion.

The framework evaluates whether ontology-informed borrowing may improve sensitivity and support earlier signal detection in spontaneous reporting systems.

### Status
Currently under peer review.

## Ontology-based Semantic Similarity Measures for Clustering Medical Concepts in Drug Safety

**AMIA Annual Symposium Proceedings (2025)**  
Presented at the AMIA 2025 Fall Symposium, Atlanta, GA

### Published Version
https://pubmed.ncbi.nlm.nih.gov/41726515/

### Preprint
https://arxiv.org/abs/2503.20737

### Source Code
https://github.com/GSK-Global-Safety/semantic-similarity

### Summary

This work evaluates ontology-based semantic similarity measures for clustering pharmacovigilance concepts using integrated MedDRA and SNOMED-CT relationships. Multiple semantic similarity approaches were compared against expert-reviewed groupings to assess their ability to capture clinically meaningful relatedness.

## PVLens: Enhancing Pharmacovigilance Through Automated Label Extraction

**AMIA Annual Symposium Proceedings (2025)**  
Presented at the AMIA 2025 Fall Symposium, Atlanta, GA

### Published Version
https://pubmed.ncbi.nlm.nih.gov/41726524/

### Preprint
https://arxiv.org/abs/2503.20639

### Source Code
https://github.com/GSK-Global-Safety/pvlens

### Summary

PVLens is a pharmacovigilance evidence extraction framework for processing FDA Structured Product Labeling (SPL) documents. The system automates extraction and normalization of adverse event and indication information from regulatory labeling documents using ontology-driven NLP methods.

## Additional Related Research


### PVLens: Time-Indexed Pharmacovigilance Evidence Extraction

Development of a European Union Time-Indexed Reference Dataset for Assessing the Performance of Signal Detection Methods in Pharmacovigilance using a Large Language Model
Kefala M, Painter JL, Bukhari ST, Sessa M.
arXiv preprint, 2026.

https://arxiv.org/abs/2603.26544

This work extends the PVLens framework to construct a large-scale European Union time-indexed reference dataset using historical SmPC versions and LLM-assisted adverse event extraction. The resulting dataset enables temporally valid evaluation of signal detection methodologies by restricting analyses to pre-confirmation periods and tracking the evolution of safety labeling over time.

### CTG-DB: Clinical Trial–Gene–Drug Knowledge Integration

**AMIA Annual Symposium Proceedings (2026)**

https://arxiv.org/abs/2603.15936

This work explores integrated biomedical knowledge representation across clinical trials, genes, drugs, and therapeutic relationships to support downstream pharmacovigilance and translational research applications.
